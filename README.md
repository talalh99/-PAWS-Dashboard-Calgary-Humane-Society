# -PAWS-Dashboard-Calgary-Humane-Society

My project during my time at the Calgary Humane Society as a Database Stewardship Intern!

Confidentiality Notice:

Due to the confidential nature of the organizational and constituent data used in this project, screenshots of the dashboard, source datasets, and other sensitive project materials cannot be publicly shared.
This repository therefore focuses on documenting the **data analysis methodology, workflow, tools, and technical skills** used throughout the project. Specific data values, records, visuals, and other confidential information have been intentionally excluded to respect the Calgary Humane Society's data privacy and confidentiality requirements.

Overview:

The PAWS Dashboard was a data analysis and business intelligence project completed during my Database Stewardship Internship at the Calgary Humane Society.

The goal of the project was to transform organizational data into an interactive Power BI dashboard that could help staff and leadership better understand key trends and patterns within the available data.

The project involved the complete data analytics workflow:

Data Collection → Data Cleaning → Data Validation → Data Exploration → Analysis → Visualization → Dashboard Development → Presentation & Insights

The final dashboard was presented to managers, directors, and senior leadership at the Calgary Humane Society.

Project Objectives:

The primary objectives of the project were to:

* Analyze organizational data to identify meaningful trends and patterns.
* Clean and prepare data for analysis.
* Identify and address data-quality issues.
* Use Excel and PivotTables to explore and summarize the data.
* Develop an interactive Power BI dashboard.
* Create clear and meaningful data visualizations.
* Translate analytical findings into information that could be understood by non-technical stakeholders.
* Present the final dashboard and findings to organizational leadership.

1. Data Collection & Preparation

The first stage of the project involved obtaining the relevant organizational data needed for analysis.

The data originated from organizational systems used by the Calgary Humane Society. Before creating any visualizations, I first reviewed the available fields and assessed the data structure to determine what information could be used for the dashboard.

I examined:

* Available columns and fields
* Data types
* Missing or incomplete values
* Duplicate records
* Inconsistent formatting
* Categorical values
* Date-related information
* Relevant metrics and dimensions
* Relationships between different pieces of information

The purpose of this stage was to understand the dataset before making analytical or visualization decisions.

2. Data Cleaning

Before analyzing the data, I performed data-cleaning and preparation steps to improve its quality and consistency.

The cleaning process included:

* Identifying duplicate or potentially duplicate records
* Reviewing incomplete or missing information
* Standardizing inconsistent values
* Reviewing addresses and postal-code information where applicable
* Checking categorical fields for inconsistent naming
* Reviewing data types and formatting
* Removing or correcting data that could negatively affect analysis
* Ensuring fields were consistently formatted for use in Excel and Power BI

Data cleaning was an important part of the project because inaccurate or inconsistent source data can lead to misleading visualizations and conclusions.

3. Data Validation

After cleaning the dataset, I performed validation checks to ensure the information being used for analysis was reasonable and consistent.

I compared summarized information and reviewed records to identify potential discrepancies.

Validation included:

* Checking record counts
* Reviewing totals
* Comparing categories
* Investigating unexpected values
* Checking for missing information
* Confirming that cleaned data was consistent with the source information

This helped ensure that the dashboard was based on reliable data.

4. Exploratory Data Analysis

After preparing the dataset, I used **Excel and PivotTables** to begin exploring the data.

PivotTables allowed me to summarize the information and identify patterns before deciding which metrics and visualizations would be most useful for the final dashboard.

I used exploratory analysis to investigate:

* Distribution of records across categories
* Trends within the available data
* Differences between categories
* Key counts and totals
* Potential outliers or unusual values
* Relationships between relevant fields

This stage helped determine which information would provide the most value in the final Power BI dashboard.

5. PivotTable Analysis

I created PivotTables to summarize the cleaned data and make the information easier to analyze.

The PivotTables were used to:

* Group records into meaningful categories
* Calculate totals and counts
* Compare different categories
* Identify trends
* Validate calculations
* Explore potential insights before building the dashboard

Using PivotTables also provided a way to independently review the data before transferring the analysis into Power BI.

6. Power BI Development

Once the data had been cleaned and analyzed, I imported the prepared data into **Microsoft Power BI**.

I then developed the dashboard around the key metrics and trends identified during the exploratory analysis.

The Power BI development process included:

1. Importing the prepared dataset.
2. Reviewing data types and fields.
3. Organizing relevant fields for analysis.
4. Creating calculated metrics where appropriate.
5. Selecting appropriate visualization types.
6. Building charts and summary visuals.
7. Organizing visuals into a logical dashboard layout.
8. Adding filters/slicers where appropriate.
9. Reviewing the dashboard for accuracy and usability.
10. Refining the design based on the information the dashboard needed to communicate.

7. Data Visualization

I selected visualizations based on the type of information being communicated.

The dashboard included visual elements designed to make important information easier to understand and interpret.

Examples of visualization approaches included:

* KPI / summary metrics
* Bar and column charts
* Category comparisons
* Trend visualizations
* Distribution summaries
* Interactive filters
* Tables or detailed views where appropriate

The focus was not simply on creating visually appealing charts, but on making the information **clear, relevant, and useful for decision-making**.

8. Dashboard Design

I organized the dashboard so that users could quickly understand the most important information.

The design process considered:

* Information hierarchy
* Readability
* Appropriate chart selection
* Consistent formatting
* Ease of navigation
* Avoiding unnecessary visual clutter
* Highlighting important metrics
* Making the dashboard understandable to non-technical users

The goal was to create a dashboard that could be used by organizational stakeholders without requiring them to understand the underlying technical data-processing steps.

9. Analysis & Insights

After developing the dashboard, I reviewed the visualizations to identify meaningful trends and patterns within the data.

Rather than simply presenting charts, I focused on understanding what the data was showing and how those findings could be communicated to stakeholders.

The analysis involved:

* Identifying notable trends
* Comparing categories
* Reviewing changes and distributions
* Investigating unusual results
* Connecting findings back to the underlying data
* Determining which findings were most relevant to stakeholders

10. Presentation to Leadership

The completed dashboard and analysis were presented to **managers, directors, and senior leadership** at the Calgary Humane Society.

During the presentation, I:

* Explained the purpose of the dashboard.
* Walked stakeholders through the key visualizations.
* Discussed important findings and trends.
* Explained how the data had been prepared and analyzed.
* Answered questions regarding the analysis and dashboard.
* Demonstrated how the dashboard could be used to explore the information.

This was an important part of the project because it required translating technical data analysis into information that could be communicated clearly to a non-technical audience.

13. Business Impact

The project transformed organizational data into an interactive dashboard that provided stakeholders with a more accessible way to explore and understand the information.

The project demonstrated how data can move from a raw organizational dataset through **cleaning, validation, analysis, visualization, and communication** to support informed decision-making.
